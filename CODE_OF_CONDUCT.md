# Community code of conduct

Treat contributors and users with respect. Discuss technical choices directly, give actionable feedback, acknowledge uncertainty and make room for people with different experience levels.

Harassment, threats, discriminatory abuse, sexualized attention, doxxing and sharing another person's private information are not acceptable. Disagreement about code is welcome; personal attacks are not. Do not fabricate activity, impersonate others or misrepresent contributions.

These expectations apply to this repository's issues, pull requests and project discussions. Maintainers may edit/remove inappropriate content, close interactions, or restrict participation proportionately. They should explain decisions where practical while protecting privacy.

Report public conduct problems using GitHub's reporting controls. For sensitive project matters, request a private contact channel without posting the sensitive details; the security reporting path in SECURITY.md can be used when available. No guaranteed response time or external enforcement authority is implied.
